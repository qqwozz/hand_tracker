# 🔥 Hand Tracker Pro — трекинг рук в реальном времени

> **Ультра-гладкий, молниеносный и стильный трекер рук** на базе MediaPipe Hand Landmarker.  
> Сглаживание, зеркало, скриншоты, 4 режима отображения — всё, что нужно для крутых демо и разработки.

## 🚀 Возможности

- **🚀 Высокая производительность** — обработка кадров с настраиваемой частотой (каждый N-й кадр).
- **✨ Сглаживание координат** — экспоненциальное сглаживание (дрожание рук уходит в прошлое).
- **🪞 Зеркальный режим** — удобно для работы с камерой (как в Zoom).
- **📸 Мгновенный скриншот** — сохраняйте лучшие моменты одним нажатием `S`.
- **🎨 4 режима отображения**:
  - `1` — только скелет
  - `2` — только ключевые точки
  - `3` — только подписи пальцев (Thumb, Index, …)
  - `4` — всё вместе (полный фарш)
- **🖐️ Поддержка до 2 рук** (можно увеличить).
- **📊 Отображение FPS** — всегда знаешь, как летает.

## ⚙️ Установка

### 1. Клонируйте репозиторий (или просто скачайте скрипт)

```bash
git clone https://github.com/yourname/hand-tracker-pro.git
cd hand-tracker-pro
```

### 2. Установите зависимости

```bash
pip install -r requirements.txt
```

Файл `requirements.txt`:
```
opencv-python>=4.5.0
mediapipe>=0.10.0
numpy>=1.21.0
```

### 3. Скачайте модель MediaPipe

Программа требует файл модели `hand_landmarker.task`.  
Скачайте его в папку проекта:

```bash
wget https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/1/hand_landmarker.task
```
или
```bash
curl -O https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/1/hand_landmarker.task
```

### 4. Запустите!

```bash
python hand_tracker.py
```

## 🎮 Управление (горячие клавиши)

| Клавиша | Действие |
|---------|----------|
| `M`     | Включить/выключить зеркало |
| `S`     | Сохранить скриншот в текущую папку (имя `hand_<timestamp>.png`) |
| `1`     | Режим **Скелет** |
| `2`     | Режим **Точки** |
| `3`     | Режим **Подписи пальцев** |
| `4`     | Режим **Всё вместе** (по умолчанию) |
| `Q`     | Выйти из программы |

## ⚡ Тонкая настройка

Внутри `main()` вы можете поиграть с параметрами:

```python
PROCESS_EVERY_N_FRAMES = 2   # 1 – каждый кадр, 2 – каждый второй и т.д.
SMOOTH_ALPHA = 0.3           # 0..1: меньше – сильнее сглаживание, больше – быстрее реакция
```

- Если хотите максимальную плавность — увеличьте `SMOOTH_ALPHA` (0.1–0.2).
- Если нужно минимальное отставание — поставьте `SMOOTH_ALPHA = 0.8` или `1.0` (отключить сглаживание).

## 🧠 Как это работает (коротко)

1. **Захват видео** через OpenCV.
2. **Детектор** на основе MediaPipe Hand Landmarker (новый API `tasks`).
3. **Сглаживатель** — хранит предыдущие координаты и применяет экспоненциальное скользящее среднее.
4. **Отрисовка** — рисует скелет, точки, подписи в зависимости от режима.
5. **Управление** — реагирует на клавиши в реальном времени.

Весь код завёрнут в один файл, но легко расширяется.

## 🐛 Частые проблемы и решения

| Проблема | Решение |
|----------|---------|
| `FileNotFoundError: model not found` | Скачайте `hand_landmarker.task` в папку со скриптом. |
| Камера не открывается | Проверьте, что камера подключена, или измените индекс в `cv2.VideoCapture(0)` на `1` или `2`. |
| Низкий FPS | Увеличьте `PROCESS_EVERY_N_FRAMES` (например, до 3) или уменьшите размер окна. |
| MediaPipe не импортируется | Обновите mediapipe: `pip install --upgrade mediapipe` |
